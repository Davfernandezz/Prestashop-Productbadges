# Product Badges para PrestaShop 1.7

Módulo para PrestaShop 1.7 que permite crear y gestionar etiquetas visuales reutilizables para productos, como "NUEVO", "OFERTA", "EXCLUSIVO" o "ÚLTIMAS UNIDADES".

El módulo permite administrar badges desde el back office, asignarlas a productos y mostrarlas en el frontend sobre la imagen del producto.

## Requisitos

- PrestaShop 1.7.8.x
- Probado en PrestaShop 1.7.8.11
- PHP 7.4 / 8.1
- MySQL o MariaDB compatible con PrestaShop
- Módulo sin dependencias externas de Composer


## Instalación

Pendiente de completar cuando el módulo sea instalable desde el back office.
